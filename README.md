# V12.1 修复版：数据停在 10 月 27 日、研究员不显示号码

**本次为 V12 的兼容修复，保留 IndexedDB 数据库 `lottery_v12` 和研究记录结构，不清空旧数据。**

## 修复的问题

1. CDN 返回 HTTP 200 但内容旧时，V12 会停止寻找更新数据。修复版同时比较 CDN、GitHub raw、仓库快照的有效数据，并合并最新期次，禁止用旧数据覆盖新数据。
2. 加入一次性人工核对的 2026-10-29 双色球第 **2026124** 期真实开奖：红球 **03 11 17 22 23 29**，蓝球 **09**。该核对依据四川省福利彩票官网及上海市福利彩票发行中心官网公开开奖公告，文件 `official_latest.json`；仅作为一次性补漏，绝不宣称它以后能自动更新。
3. 首页和“研究战绩”页显示当前 A/B/C 三位研究员各一组实际候选号码，包括红球/蓝球或大乐透前后区，且可展开每个号码的算法理由。数据不足30期时明确提示。
4. 显示最新期号和日期，以及可能的数据滞后提示；数据源地址是否成功访问与数据是否更新分开判断。
5. 为 JS/CSS/PWA 缓存增加 **12.1** 版本参数，解决旧 Service Worker 继续提供 V12 脚本的情况。

## iPhone 上传（建议先做完整备份）

1. 解压本 ZIP；在 GitHub 仓库根目录上传以下 **11 个文件**：`index.html`, `styles.css`, `core.js`, `engine.js`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `sync_history.py`, `official_latest.json`, `README.md`。
2. 点击 Commit changes，等待 Pages 发布完成。无需再设置 Pages。
3. 用 Safari 打开原网站，确认顶部 **V12.1**。先看双色球最新是否显示 **2026124 · 2026-10-29**，再看总览底部的三组研究号码，或进入“研究战绩”查看本期 A/B/C 号码。
4. 如看到旧版，不要清空 Safari 网站数据。请刷新网页或通过 Safari 新建普通标签页打开带 `?v=12.1` 的网址。

如暂时不方便更新程序，可在旧 V12「数据与备份 → 本地 CSV 导入」文本框输入：

```
game,issue,date,main,extra
ssq,2026124,2026-10-29,03 11 17 22 23 29,09
```

这只能临时补充开奖数据，**不会修复 V12 的研究员展示和同步源过旧问题**。

`official_latest.json` 为固定快照；后续数据仍需第三方在线源或正确安装并运行 GitHub Actions 数据更新流程。GitHub Pages 自身不运行 Python，ZIP 隐藏目录 `.github/workflows` 在 iPhone 上传时需另外处理（仅已有工作流正常运行时不必重复安装）。

## 注意

策略生成依赖至少30期有效历史数据。三组号码是参考候选，不是实际中奖预测。候选自动展示 **不等于锁定**；只有点击“锁定当前结果并建立档案”后才进入本机实盘记录，而且本机记录不可作为独立防篡改证据。
