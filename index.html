版本与研究边界

  • 源码模块化：core.js / engine.js / app.js，可独立自动测试。
  • 本机使用 IndexedDB，若不可用则回退 localStorage；离线能力依赖首次成功加载。
  • 随包提供 GitHub Actions 自动同步工作流，启用后可将公开来源数据写入本站 history.json。
  • 历史走势、经验规则、杀号的效果都必须与随机基准比较；不鼓励过度投注。
